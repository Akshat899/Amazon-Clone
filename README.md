# 🛒 Amazon Clone - E-Commerce Website

## 📌 Overview
This is a **fully responsive, professional, and polished** Amazon Clone website designed to showcase **UI/UX design prowess** in creating modern e-commerce platforms. The website features a **stunning homepage, product pages, cart system, and user-friendly navigation**, ensuring a seamless shopping experience.

## 🎯 Features
- 🏠 **Homepage** with banner sliders & featured products
- 🔍 **Advanced Search Bar** for quick product lookups
- 📦 **Product Listings & Individual Product Pages**
- 🛒 **Shopping Cart** with smooth animations
- 📑 **Checkout Page** with form validation
- 🎨 **High-Quality Animations, Hover Effects, & Transitions**
- ⚡ **Optimized for Fast Loading & Low Connectivity Areas**
- 📱 **Fully Responsive Design (Mobile, Tablet, Desktop)**

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript (Animations, Transitions, Hover Effects)
- **Backend:** Node.js, Express.js *(for full functionality)*

## 📂 Folder Structure
```
📂 amazon-clone
│── 📁 models          # Mongoose models (Products, Users, Orders)
│── 📁 routes          # API routes (Products, Cart, Orders)
│── 📁 public          # Static assets (Images, CSS, JS)
│── 📁 views           # EJS templates (Frontend Pages)
│── server.js         # Main Express server file
│── .env              # Environment variables (Database & API keys)
│── package.json      # Project dependencies & scripts
│── README.md         # Project documentation (This file)
```
